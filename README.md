# StayService — Система автоматизации допуслуг гостиничного комплекса

---

## О проекте

**StayService** — это информационная система для автоматизации дополнительных услуг гостиничного комплекса: бронирование бани, СПА, лежаков и столиков, заказ еды в номер, вызов персонала, запись на мероприятия.

Система интегрируется с основным программным обеспечением гостиницы и предоставляет гостям единый интерфейс для управления сервисами как до заселения, так и во время проживания.

**Проблема:** Ручное управление допуслугами приводит к ошибкам, задержкам и недовольству гостей.

**Решение:** Единый цифровой интерфейс для гостей, администраторов и персонала, автоматизирующий все процессы взаимодействия с дополнительными услугами отеля.

---

## Целевая аудитория

- **Гости гостиницы** — бронирование услуг, заказ еды, вызов персонала
- **Администраторы** — управление услугами, ценами, бронированиями
- **Персонал** (горничные, повара, техники) — получение задач и обновление статусов

---

## Цели и задачи

**Цель:** Автоматизировать процессы управления дополнительными услугами гостиничного комплекса для повышения качества обслуживания и увеличения выручки от допуслуг.

**Задачи:**
- Реализовать двухуровневую авторизацию гостей (по номеру бронирования до заселения и по коду доступа после заселения)
- Обеспечить интеграцию с основным ПО гостиницы через REST API для передачи данных при заселении
- Реализовать просмотр и бронирование допуслуг с цветовой индикацией доступности слотов
- Предоставить онлайн-меню ресторана с возможностью заказа еды в номер
- Внедрить модуль вызова персонала с выбором типа запроса и автоматическим определением номера комнаты
- Обеспечить запись на мероприятия с контролем лимита участников
- Разработать админ-панель для управления услугами, ценами и формирования отчётов
- Предоставить интерфейс для персонала с доступом к задачам и возможностью обновления статусов
- Реализовать механизм экстренной связи с гостями в форс-мажорных ситуациях

---

## Ключевые функции

### Для гостей:
- Бронирование допуслуг (баня, СПА, лежаки, столики)
- Заказ еды в номер с выбором времени подачи
- Вызов персонала (горничная, техподдержка, полотенца)
- Запись на мероприятия и анимацию
- Просмотр расписания активностей
- Личный кабинет со всеми бронированиями и заказами

### Для администраторов:
- Управление услугами и ценами
- Просмотр всех бронирований и заказов
- Назначение персонала на заявки
- Формирование отчётов
- Экстренная связь с гостями

### Для персонала:
- Просмотр личных задач
- Обновление статусов выполнения
- Уведомления о новых задачах

## Архитектура

**Технологический стек:**
- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **API:** REST API, OpenAPI 3.0
- **Notifications:** SMTP / Push-уведомления

## Интеграции

Система интегрируется с основным ПО гостиницы через REST API:
- При заселении автоматически передаются данные гостя (номер бронирования, код доступа, номер комнаты)
- Реализована идемпотентность — повторная отправка с тем же номером бронирования обновляет запись
